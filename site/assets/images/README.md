# assets/images

วางรูปจริงไว้ในโฟลเดอร์นี้ แล้วแก้ path ใน `site/js/data.js` ให้ชี้มาที่ไฟล์

| ไฟล์ | ใช้ที่ |
| --- | --- |
| `profile.png` | รูปโปรไฟล์ (PNG พื้นหลังโปร่งใส) บน Banner หน้า Profile |
| `camera.png` | รูปกล้อง (PNG พื้นหลังโปร่งใส) บน Banner หน้า Gallery |
| `film-lansang-person.png` | รูปคน (ตัดพื้นหลัง) หน้า Film — เรื่อง Lan Sang |
| `film-2-person.png`, `film-3-person.png` | รูปคนของหนังเรื่องอื่น ๆ |
| `gallery/2026-01.jpg` ... | รูป Gallery แนะนำอัตราส่วน 1:1 |

ถ้ายังไม่มีไฟล์ หน้าเว็บจะแสดง placeholder หรือซ่อนรูปนั้นอัตโนมัติ
